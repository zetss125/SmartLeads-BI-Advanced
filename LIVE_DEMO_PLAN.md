# Live Demo Implementation Plan

## Phase 1: Shared Live Backend

Success criteria:

- Live lead counts are produced by a shared in-memory API.
- Approval requests and social comments are stored in memory.
- Live graph history is generated from the same backend state.

Status: Complete

## Phase 2: Dashboard And Live Counts

Success criteria:

- Dashboard shows live lead, customer, and approval counts.
- Dashboard has buttons for growth graph, approval flow, and mock social flow.
- Leads and Social Analytics pages update live from the same source.

Status: Complete

## Phase 3: Mock User Flows

Success criteria:

- Approval simulation shows email request, form submission, and confirmation.
- Submitted approvals create approved records and scored leads.
- Mock social replies create comments and scored leads.
- Live growth graph updates while the app is open.

Status: Complete

## Phase 4: Documentation And Validation

Success criteria:

- README describes the current app and live demo flows.
- Agent notes describe the updated architecture and APIs.
- Build passes.
- Dev server can run for user testing.

Status: Complete
